# Acuvera Clinical

Acuvera Clinical est une page de destination (landing page) moderne et haut de gamme conçue pour un centre de recherche clinique ou une institution médicale. Le design s'inspire du style "Memphis" avec des touches modernes, incluant des transitions de vagues fluides entre les sections, un carrousel de centres de recherche interactif, et une esthétique médicale soignée et professionnelle.

## Fonctionnalités Principales

*   **Design Premium et Cohérent :** Utilisation d'un système de couleurs harmonieux et d'une typographie moderne pour inspirer confiance et professionnalisme.
*   **Transitions Fluides :** Séparateurs en forme de vagues (Wave Separators) entre les sections pour une navigation douce et sans ruptures visuelles abruptes.
*   **Carrousel Interactif :** Présentation dynamique et engageante des différents centres de recherche.
*   **Responsive Design :** Interface entièrement adaptable à tous les types d'écrans (mobiles, tablettes, ordinateurs de bureau).

## Structure du Projet

Le projet est construit de manière simple et efficace, sans dépendances complexes :

*   `acuvera clinical..html` : Le fichier principal contenant la structure HTML, les styles CSS intégrés et la logique interactive JavaScript.
*   `assets/` : Le dossier destiné à contenir les ressources statiques du projet telles que les images, illustrations ou vidéos.

## Comment Lancer le Projet Localement

Étant donné qu'il s'agit d'un projet web statique, aucune installation de serveur ou de dépendance n'est requise.

1.  Ouvrez le dossier du projet sur votre ordinateur : `/home/affirmatif/Documents/Projet/acuvera clinical/`.
2.  Double-cliquez sur le fichier `acuvera clinical..html` pour l'ouvrir directement dans votre navigateur web préféré (Chrome, Firefox, Safari, etc.).
3.  *Astuce de développement :* Si vous utilisez un éditeur comme VS Code, vous pouvez utiliser l'extension "Live Server" pour ouvrir le fichier et bénéficier du rechargement automatique à chaque modification.

## Technologies Utilisées

*   **HTML5 :** Pour la structure sémantique.
*   **CSS3 :** Pour le style, incluant les variables CSS pour une gestion facile du thème, et des animations pour rendre l'interface vivante.
*   **JavaScript (Vanilla) :** Pour gérer les interactions de l'utilisateur, comme le fonctionnement du carrousel.

## Développement Futur

Pour les prochaines itérations, il est recommandé de :
- Séparer le CSS et le JavaScript dans des fichiers distincts (`style.css`, `script.js`) pour une meilleure maintenabilité si le projet grandit.
- Optimiser les images du dossier `assets` pour garantir des temps de chargement rapides.
